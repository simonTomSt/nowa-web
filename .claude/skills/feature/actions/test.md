# Test Action

1. Identify utility functions and hooks added/modified for this feature
2. Check if tests already exist for these
3. For functions with testable logic, write unit tests using Vitest:
   - Focus on utilities and hooks (not components)
   - Test happy path and error cases
   - Do not write tests just to write them — use your best judgement
4. Run `pnpm test` to verify all tests pass
5. Report test coverage for the new feature code
